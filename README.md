## ✨ Funcionalidades

* Apresentação pessoal e profissional;
* Seção de projetos;
* Formulário de contato;
* Layout responsivo;
* Tema claro e escuro;
* Navegação entre páginas;
* Interações e manipulação de elementos através do **DOM**.

## 🧠 Conceitos aplicados

O projeto foi desenvolvido com foco na prática de fundamentos do desenvolvimento web, incluindo:

* **HTML5** — estruturação e semântica;
* **CSS3** — estilização e responsividade;
* **JavaScript** — lógica e interatividade;
* **DOM (Document Object Model)** — seleção, manipulação e atualização dinâmica de elementos da página;
* **Bootstrap** — componentes e recursos de interface;
* **Git/GitHub** — versionamento e organização do projeto.

## 🚀 Como executar

Não há necessidade de servidor ou banco de dados.

```bash
git clone https://github.com/davi-ruan-alves/portfolio.git
cd portfolio
```

Depois, abra o arquivo `index.html` no navegador.

Para desenvolvimento, recomenda-se utilizar o **Live Server**.
